Set up once (2 minutes)
  1. Tap Download, open the file and allow Install unknown apps. If Play Protect warns, tap More details → Install anyway. This one file is the whole app — the printer setup (SAI Print icon) comes inside it; do not install an older SAI Print file over it.
  2. Open SAI WOS and tap Allow on every question (camera, microphone, location, notifications, nearby devices) and on battery.
  3. Pair both printers in the phone's Bluetooth settings (PIN 0000 or 1234). USB printers: plug in with an OTG cable.
  4. Open the SAI Print icon (or Biller → print settings → Printer setup) → under Receipt printer tap Bluetooth / USB / WiFi IP and pick the thermal printer. A test slip prints.
  5. Under Label printer pick the Xprinter. A test label prints.
  6. Use SAI WOS for billing. Print settings say ✔ Printing built into the SAI WOS app. Every bill, label and sticker prints straight away. You can remove the old app made with Median.
